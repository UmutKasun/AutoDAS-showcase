Auto DAS — Vehicle Damage Detection Prototype

Auto DAS is an educational prototype exploring vehicle damage detection from images using computer vision. It was developed during my software engineering internship.

What the prototype does

Accepts a vehicle image through a Gradio interface

Runs a YOLO-based detection workflow

Displays the model's predictions for inspection

Technologies

Python · PyTorch · YOLO · Gradio

Project scope

This is a prototype, not a production-ready damage assessment or insurance decision system. Its source code, model weights, and dataset are not published in this repository.
